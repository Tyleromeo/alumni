# SVA BFA Film Alumni Page Concept

A static, GitHub Pages–ready version of the SVA BFA Film alumni website concept.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open the repository’s **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then save.

GitHub will provide a public address similar to:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Editing

All layout, content, styling, and interactions are contained in `index.html`. No build tools or package installation are required.

## Image-rights note

The concept uses externally hosted promotional thumbnails for identification and discussion of alumni work. Confirm image permissions, alumni information, credits, and class years before a public launch.
